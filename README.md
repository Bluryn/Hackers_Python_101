# 🐍 Python for Hackers — Getting Started

> A beginner-friendly Python project focused on setup, scripting basics, and small offensive security use cases.

---

## 🎯 Goal

This project helps you get started with Python as a hacker by walking through:

- Setting up your Python development environment
- Learning essential scripting concepts
- Automating basic offensive tasks like brute forcing, reconnaissance, or file parsing
